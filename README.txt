💗 PROPUESTA PARA JENNIFER — FOTO COMPLETA + GALAXIA MÁGICA 💗

Esta es la versión actualizada para computadora y celular.

¿QUÉ CAMBIÓ?
- La foto de las dos chicas aparece COMPLETA, sin recortar la imagen.
- En computadora, el retrato aparece a la izquierda y el texto a la derecha.
- El fondo difuminado rellena los espacios vacíos sin deformar la foto.
- En celular la imagen también se adapta entera al espacio disponible.
- La galaxia tiene nebulosas de colores, estrellas animadas, órbitas de luz,
  corazón brillante, una estrella fugaz y palabras bonitas distribuidas por la pantalla.
- Se conservan los botones «Sí» y «No», la sorpresa y el reproductor.

🎵 CÓMO AGREGAR TU MP3
1. Coloca tu archivo de música en ESTA MISMA CARPETA.
2. Cámbiale el nombre exactamente a: cancion-jennifer.mp3
3. Ejecuta index.html con Live Server de VS Code y haz la prueba.
4. Presiona «Sí, quiero» y después «🎁 Para ti 🎁».
   El navegador intentará reproducir la canción completa desde ese toque.
   Si el navegador bloquea la reproducción, podrás tocar ▶.

El archivo MP3 NO está incluido en este ZIP. Para publicar música con
copyright en GitHub Pages necesitas contar con permiso para distribuirla.

📂 ARCHIVOS
  index.html — pantallas de la propuesta
  style.css — estilos y animaciones
  script.js — botones, estrellas y audio
  fondo-jennifer.png — imagen de las dos chicas
  cancion-jennifer.mp3 — tu archivo (debes agregarlo tú)

📱 PARA PUBLICAR EN GITHUB PAGES
Coloca los archivos juntos dentro del repositorio y publica index.html.
El nombre de la imagen y el audio debe coincidir exactamente con el código.
